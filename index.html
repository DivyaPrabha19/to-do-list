❓ Help

How to add a task?

Type your task in the input field and click "Add" or press Enter. Select priority before adding.

How to use voice input?

Click the microphone icon and speak your task. It works in Chrome and Edge browsers.

How does search work?

Type in the search bar to filter tasks in real-time. It searches across task text.

How to archive a task?

Click the yellow archive button on any task. Find archived tasks in the sidebar under Archive.

How to use the calendar?

Switch to History tab. Tasks are shown directly on calendar dates. Click a date to see full details.

How to create labels?

Open the hamburger menu, go to "Create New Label", enter a name and pick a color.

How do reminders work?

Go to Reminders in the sidebar. Set a text and date/time. You'll be alerted when the time comes.

Backend connection

This app uses a Python Flask backend with MongoDB Atlas. Make sure the backend is running on port 5000.
